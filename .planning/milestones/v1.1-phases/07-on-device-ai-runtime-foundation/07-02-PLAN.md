<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local metrics store -> prompt assembler | Sensitive health-derived values cross into generated prompt text. |
| orchestrator -> runtime gateway | Runtime failure paths can expose internal error details if not normalized. |
| fallback output -> UI surfaces | User-visible text must remain deterministic, safe, and non-diagnostic. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | I | PromptAssembler | mitigate | Restrict assembler API to aggregate metric DTOs, redact identifiers/free text, and test for leakage of raw biometric fields. |
| T-07-06 | T | InferenceOrchestrator failure mapping | mitigate | Normalize all runtime errors to controlled reason enums and fallback payload, never forward raw stack traces/user-visible internals. |
| T-07-07 | D | Runtime fallback switching | mitigate | Enforce timeout and cooperative cancellation in orchestrator; always return deterministic fallback instead of retry loops. |
| T-07-08 | R | Fallback reason observability | mitigate | Emit structured reason code and latency metadata for each inference outcome; verify through unit tests. |
| T-07-09 | S | Prompt role/content injection | mitigate | Keep system and user prompt chunks separate and sanitize user text before concatenation. |
</threat_model>
