<decisions>
## Implementation Decisions

### Design source of truth

- Root designs folder is authoritative for this phase: `designs/*/code.html` and `designs/aira_intelligence/DESIGN.md`.
- "Close enough" styling is not acceptable for final pass; visual hierarchy, spacing rhythm, contrast language, and motion intent must map to source designs.

### Runtime data integrity

- Production UI must not ship hardcoded mock score values, static fake narratives, or sample histories.
- Primary surfaces (Home, details, coach, train, nutrition, supplementary insight surfaces) must read from repository/Room/domain outputs.
- Preview and debug fixtures are allowed only in non-production contexts.

### Navigation and flow quality gates

- No placeholder routes in primary user journeys.
- Onboarding gate must correctly control first-entry path before main shell.
- Deep links and bottom-nav tab flows must resolve to functional destinations.

### Verification expectations

- Compile must stay green through all rework slices.
- UAT in `04-UAT.md` must be replayed and updated with evidence after implementation.

### the agent's Discretion

- Exact wave grouping and plan decomposition for execution.
- Specific test split between unit/UI/integration checks per plan.
- Fine-grained naming and ordering of plan files in this phase directory.
  </decisions>
