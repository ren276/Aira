<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| benchmark harness -> production app runtime | Test harness drives real runtime path and can bias/skip critical behavior if misconfigured. |
| benchmark outputs -> gate script | Performance metrics cross from generated files into pass/fail logic. |
| CI environment -> release decisions | Automated gate outcome influences release readiness decisions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-10 | T | Benchmark output files | mitigate | Validate expected schema/fields in parser; fail closed on missing metrics or malformed files. |
| T-07-11 | R | Perf gate evidence | mitigate | Persist benchmark artifacts and include device metadata in summary for auditability. |
| T-07-12 | D | Runtime under perf stress | mitigate | Run capped iteration counts with watchdog timeout and abort conditions to avoid prolonged device instability. |
| T-07-13 | I | Benchmark logs | mitigate | Ensure logs contain only aggregate metrics and no raw biometric payloads; redact prompt content in benchmark traces. |
| T-07-14 | S | CI benchmark execution context | mitigate | Pin Gradle tasks, target package, and benchmark class names explicitly to prevent spoofed/incorrect benchmark paths. |
</threat_model>
