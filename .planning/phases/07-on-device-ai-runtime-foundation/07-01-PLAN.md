<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model file path -> runtime loader | Untrusted file path or tampered artifact can be fed into native runtime loading. |
| app coroutine scope -> native inference session | Cancellation and timeout signals cross into JNI/native runtime execution. |
| prompt feature assembly -> runtime input | Sensitive local health signals are transformed into text prompt payloads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | T | MediapipeRuntimeGateway model loading | mitigate | Restrict model path to app-private directory, verify checksum before load, reject unexpected extension/path traversal. |
| T-07-02 | D | Runtime execution path | mitigate | Force background dispatcher, enforce timeout and cancellation propagation, close sessions in finally to prevent resource exhaustion. |
| T-07-03 | I | Runtime request handling | mitigate | Keep request payload in-memory only, do not log raw prompt chunks, and expose only reason codes/metrics in diagnostics. |
| T-07-04 | E | Hilt runtime binding | mitigate | Bind gateway as singleton in app scope only, no dynamic class loading or reflection-based provider override in release builds. |
</threat_model>
