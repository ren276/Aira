<threat_model>

## Trust Boundaries

| Boundary                                      | Description                                                             |
| --------------------------------------------- | ----------------------------------------------------------------------- |
| Room raw data -> score orchestration use case | Potentially incomplete and delayed records become derived health scores |
| backfill events -> EMA recalculation loop     | Historical inserts can alter future model state                         |
| worker runtime -> persistence layer           | Background jobs can fail mid-pipeline and leave inconsistent state      |

## STRIDE Threat Register

| Threat ID | Category | Component                                 | Disposition | Mitigation Plan                                                                                                                    |
| --------- | -------- | ----------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| T-03-07   | T        | BaselineRecalculatorUseCase               | mitigate    | Recompute deterministic per-day sequence from backfill date and persist in a controlled order to prevent state skew.               |
| T-03-08   | D        | ComputeDailyScoresUseCase                 | mitigate    | Null-safe aggregation with bounded defaults and confidence downgrade to avoid crash/score suppression on sparse data.              |
| T-03-09   | R        | HealthSyncWorker ingest->compute pipeline | mitigate    | Keep worker success/failure deterministic and covered by tests/compile checks so retries do not silently skip score recomputation. |

</threat_model>
