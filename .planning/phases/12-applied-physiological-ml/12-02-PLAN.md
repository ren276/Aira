## Summary

## Key Decisions

- **Null-safe loading**: `TFLiteModelLoader.load()` returns `null` if the asset isn't bundled.
  This means models can be shipped separately (e.g. via Play Asset Delivery) without breaking
  the cold-start heuristic path.
- **Bias Corrections**: Each metric stores a single bounded float bias in [-0.1, 0.1] relative
  to the model raw output. Applied as additive correction post-inference. Bounded to prevent
  drift. Rate = 0.02 per correction.
- **EncryptedFile**: Uses `MasterKey.AES256_GCM` via Android Keystore. Raw biometrics are never
  stored in the bias file — only aggregate correction deltas.
