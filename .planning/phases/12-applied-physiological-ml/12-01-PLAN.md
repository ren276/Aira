## Key Decisions

- **Architecture**: Small 3-layer dense networks (4-6 inputs → 32 → 16 → 1). Justification:
  tiny footprint (<50KB each post-quantization), predictable latency on low-end devices.
- **Initial labels**: Ground-truth labels for initial training are generated by the existing
  heuristic engines applied to historical data from `health_connect_export.db`. This "bootstraps"
  the model with the correct prior before it begins adapting.
- **Quantization**: Dynamic-range quantization applied at conversion time via `convert_to_tflite.py`
  to reduce model size ~75% with minimal accuracy loss.
