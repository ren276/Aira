## Summary

Wire the TFLite inference classes into the existing domain engine layer via `HybridEngine`
classes that transparently blend ML predictions with the original deterministic fallback.
Expose everything via Hilt for clean injection at the use-case layer.

## Key Decisions

- **Cold-start Gate**: ML mode activates only when `usableDays >= 14`. New users always start in
  heuristic mode so they receive a good score from Day 1.
- **Named Qualifiers**: Four `@Named("recovery"|"strain"|"stress"|"sleep")` qualifiers prevent
  Hilt injection ambiguity for the four `PhysiologicalModelProxy` implementations.
- **Additive Bias**: Post-inference bias from `PersonalizedWeightsStore` keeps the base model
  stable while allowing individual adaptation without retraining.
