| Token | Value | Usage |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Apply Correction |
| Empty state heading | Not Enough Recent Data |
| Empty state body | We need at least 7 days of recent local data before ranking drivers. Keep syncing wearables and check back tomorrow. |
| Error state | Personalization update could not be applied right now. Your current baseline is unchanged. Retry after your next sync. |
| Destructive confirmation | Remove correction: Remove this correction from future personalization? This may reduce near-term explanation accuracy. |

Additional copy constraints:
- Confidence labels are fixed: High, Medium, Low.
- Recency text must be explicit: last 3d, last 7d, last 14d (no vague freshness language).

## Interaction Contract

### Causal Insight Card (CAUS-01, CAUS-02, CAUS-03)
- Show exactly top 3 contributing factors per insight card (from CONTEXT D-01).
- Each factor row must include: factor name, directional impact, contribution weight, and source window tag.
- Direction language must be explicit and signed: Increased, Decreased, Neutral.
- Recency row is mandatory and explicit: Window: last Nd.
- Confidence row is mandatory and tiered with thresholds from CONTEXT D-04:
  - High for score >= 0.75
  - Medium for score 0.40 to 0.74
  - Low for score < 0.40
- Tie-break rule for near-equal factor weights (discretion area): if absolute delta < 0.03, sort by recency descending, then factor name ascending for deterministic UI ordering.

### Personalization Baseline Surface (PPM-01, PPM-02)
- Display current adaptive baseline values and daily delta in a compact card pair:
  - Sleep need baseline.
  - Recovery/stress sensitivity baseline.
- Update cadence message must be visible: Updates once daily from local outcomes.
- Guardrail message must be visible when update is blocked:
  - Requires at least 7 days of data.
  - Max daily movement capped at +/-3%.

### User Correction UX (PPM-03)
- Correction flow must include a pre-submit impact preview:
  - Affected model area.
  - Expected influence window (14 days).
  - Influence cap (up to 20%).
- Submit action requires explicit confirmation step before mutation.
- Post-submit success state must acknowledge delayed effect:
  - Correction saved. Future explanations will adapt over the next 14 days.
- Correction deletion is destructive and must require confirmation modal text from Copywriting Contract.

### Explainability Entry Points (08-03 plan scope)
- Entry points for explanation and correction must remain available from metric detail surfaces and settings-level correction/confidence routes.
- Existing three-part explanation structure remains fixed:
  - What changed
  - Why it matters
  - What to do next

## State Contracts

| State | Required UI Treatment |
|------|------------------------|
| Loading | Skeleton placeholders for card title + 3 factor rows + confidence/recency metadata |
| Empty | Empty-state copy from contract and no placeholder factor bullets |
| Insufficient data | Show 7-day minimum requirement message and disable Apply Correction CTA |
| Error | Preserve previous baseline values; show error copy with retry affordance |
| Updated | Show confirmation banner with timestamp and influence window reminder |

---

## Accessibility and Safety

- Minimum touch target: 48dp for all interactive controls.
- Confidence must never be color-only: always include textual tier label and numeric or categorical descriptor.
- Recency text must be machine-readable plain language (no icon-only recency cues).
- Correction confirmation modal must clearly state downstream impact and reversibility.
- Keep animations subtle and functional; no motion should obscure causal ranking or confidence legibility.
