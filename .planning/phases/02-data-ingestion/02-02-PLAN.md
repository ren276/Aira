# Phase 2 - Plan 2: Google Fit Fallback Integration

## Goal
Implement Google Fit as a secondary/fallback biometric ingestion layer for Android 10-13 devices lacking Health Connect.

## Tasks

```xml
<task>
  <read_first>
    - app/src/main/java/com/aira/health/domain/repository/HealthDataRepository.kt
  </read_first>
  <action>
    Create `GoogleFitRepositoryImpl.kt` in `app/src/main/java/com/aira/health/data/repository/`.
    Inject `Context`. This implementation should also implement the `HealthDataRepository` interface.
    Use `Fitness.getHistoryClient(context, getGoogleAccount())` to formulate `DataReadRequest`s.
    For example, for Heart Rate: query `DataType.TYPE_HEART_RATE_BPM`.
    Assign the confidence mapping by interpreting the package name of the Google Fit `DataSource.appPackageName` through the `ConfidenceRouter`.
  </action>
  <acceptance_criteria>
    - File `GoogleFitRepositoryImpl.kt` is created.
    - Class implements `HealthDataRepository`.
    - Exact string `Fitness.getHistoryClient` is used.
  </acceptance_criteria>
  <requirements>DATA-02, DATA-03</requirements>
</task>

<task>
  <read_first>
    - app/src/main/java/com/aira/health/di/HealthDataModule.kt
    - app/src/main/java/com/aira/health/data/repository/GoogleFitRepositoryImpl.kt
    - app/src/main/java/com/aira/health/data/repository/HealthConnectRepositoryImpl.kt
  </read_first>
  <action>
    Modify `HealthDataModule.kt` to securely provide the correct `HealthDataRepository`.
    If `HealthConnectClient` is available (not null), return `HealthConnectRepositoryImpl`.
    Otherwise, if the user authorizes Google Fit, return `GoogleFitRepositoryImpl`.
  </action>
  <acceptance_criteria>
    - `HealthDataModule.kt` defines a `@Provides` method that returns `HealthDataRepository`.
    - Implementation routing logically falls back to Google Fit if Health Connect isn't instantiated.
  </acceptance_criteria>
  <requirements>DATA-02</requirements>
</task>
```

## Verification
- Compile `GoogleFitRepositoryImpl`.
- Ensure fallback DI mapping is correctly routed.

## Must Haves
- The application seamlessly injects Google Fit queries when Health Connect throws unavailable status.
